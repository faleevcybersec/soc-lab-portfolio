
# SOC Lab Portfolio — Практическое портфолио SOC Analyst

Практические работы по мониторингу безопасности, анализу событий и расследованию инцидентов в лаборатории на базе Wazuh SIEM.

## Обо мне

Я развиваю практические навыки в области информационной безопасности с фокусом на направление SOC Analyst L1 и Blue Team.

В этом репозитории документирую выполненные лабораторные работы: анализ событий Windows, расследование подозрительной активности, настройку правил обнаружения и проверку срабатываний SIEM.

Все результаты основаны на практических экспериментах в собственной лаборатории.

## Лабораторная среда

- **SIEM:** Wazuh
- **Конечная система:** Windows с установленным Wazuh Agent
- **Источники событий:** журналы событий Windows
- **Анализ:** проверка событий, построение временной шкалы, исследование оповещений и документирование результатов

Исследования проводятся в контролируемой лабораторной среде.

## Практические работы

### 01. Расследование событий аутентификации Windows

**Статус:** подготовка отчёта.

Цель — исследовать события успешных и неудачных входов в систему, собранные Wazuh.

В работе будут представлены:
- анализ событий Windows Event ID 4624 и 4625;
- исследование связанных событий авторизации;
- временная шкала активности;
- скриншоты и подтверждающие данные;
- оценка подозрительности наблюдаемой активности;
- выводы и рекомендации аналитика.

### 02. Обнаружение серии неудачных входов

**Статус:** запланировано.

Цель — создать и проверить пользовательское правило обнаружения повторяющихся неудачных попыток аутентификации в Wazuh.

Планируемые материалы:
- конфигурация правила;
- сценарий контролируемого тестирования;
- подтверждение срабатывания;
- результаты проверки и ограничения обнаружения.

### 03. Мониторинг целостности файлов

**Статус:** запланировано.

Настройка File Integrity Monitoring (FIM), проверка обнаружения изменений выбранных файлов и анализ соответствующих оповещений.

### 04. Анализ SSH-аутентификации в Linux

**Статус:** запланировано.

Подключение Linux-агента при необходимости, сбор событий SSH-аутентификации и исследование успешных и неудачных попыток входа.

## Методология расследования

Каждая завершённая практическая работа по возможности включает:

1. Цель и границы исследования.
2. Описание лабораторной среды.
3. Источники событий и логику обнаружения.
4. Пошаговое воспроизведение и расследование.
5. Скриншоты и подтверждающие данные.
6. Анализ результатов и временную шкалу.
7. Выводы, ограничения и возможные ложные срабатывания.
8. Рекомендации по дальнейшим действиям.

## Безопасность публикуемых материалов

Перед публикацией проверяются скриншоты, журналы событий и конфигурационные файлы.

Пароли, токены, приватные ключи и другие секретные данные не публикуются. Идентифицирующие сведения о личной лаборатории при необходимости маскируются.

## Статус портфолио

Портфолио находится в разработке. Статусы проектов будут обновляться по мере выполнения, проверки и документирования практических работ.
