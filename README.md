# SOC L1 Home Lab — Портфолио по Wazuh: детект и реагирование

Практические blue team лаборатории на базе собственного Wazuh SIEM.
Каждый проект документирует полный цикл: **симуляция атаки → детект → триаж → отчёт об инциденте**.

## 🏗 Архитектура лаборатории

| Компонент | Роль | Детали |
|---|---|---|
| Wazuh Manager + Indexer + Dashboard | SIEM | v4.14.9, all-in-one OVA |

## 🧠 Навыки, демонстрируемые в портфолио

- Развёртывание Wazuh SIEM и управление агентами
- Чтение и корреляция Linux / Windows / auth / audit логов
- Триаж алертов: severity, анализ ложных срабатываний, эскалация
- Маппинг на MITRE ATT&CK
- Написание собственных правил детекта для Wazuh
- Документирование инцидентов (резюме для руководства, таймлайн, IOC, root cause, рекомендации)

## 📌 Примечание

Все атаки выполняются в изолированной домашней лаборатории исключительно в образовательных целях.
